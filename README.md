# 📻 Custom Radio Player

**Custom Radio Player** es una aplicación para Android de código abierto (*open source*) y totalmente libre de anuncios, diseñada para que puedas gestionar y escuchar tus emisoras de radio favoritas de forma totalmente personalizada.

## ✨ Características Principales

* **➕ Emisoras personalizadas:** Añade tus propias radios rellenando el nombre (obligatorio), la URL de retransmisión (obligatoria), una frecuencia opcional (ideal para simular la frecuencia FM real) y la ciudad o localidad.
* **⏱️ Temporizador de apagado (*Sleep Timer*):** Programa el apagado automático de la reproducción para que puedas escuchar la radio antes de dormir sin preocuparte.
* **📂 Copia de seguridad en JSON:** Importa y exporta todas tus emisoras favoritas en un archivo JSON para no perder nunca tu configuración o pasarla a otro dispositivo.
* **🚫 Sin anuncios y Privada:** Disfruta de una interfaz limpia, sin publicidad intrusiva.
* **🤖 Desarrollada con IA:** Creada y optimizada con la asistencia de Inteligencia Artificial.

---

## 📖 Guía de Uso Rápida

1. **Pantalla Principal:** Visualiza tu lista de emisoras guardadas.
2. **Añadir Emisora:** Pulsa el botón de añadir para configurar una nueva radio:
   * **Nombre** (Obligatorio)
   * **URL de Stream** (Obligatorio)
   * **Frecuencia FM** (Opcional, para identificarla con diales reales)
   * **Ciudad / Localidad** (Opcional)
3. **Importar / Exportar:** Desde el menú de ajustes o gestión, puedes exportar tus emisoras a un archivo `.json` o importar una lista existente.
4. **Temporizador:** Activa el temporizador de apagado desde los controles de reproducción cuando lo necesites.
